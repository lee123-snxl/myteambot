# 群组文件

`groups.json` 是群组列表。每项有 id、name、botIds，可以有 folder。folder 是已有文件夹的绝对路径。群里的 Bot 读写的是这个文件夹。botIds 按加入顺序保存 Bot 编号。

`group-chats/{群组编号}.json` 是发言。每条有 role、content、speakerId。role 为 user、assistant 或 error。用户的 speakerId 为空。Bot 的回复和失败记下它的编号。生成了文件时还有 file，是相对路径，空则不写。见 [媒体文件](媒体文件.md)。助手回复可以有 inputTokens 和 outputTokens。两项都是 0 或没有则不写。

`group-files/{群组编号}/index.json` 是文件清单，每项有 id、name、size。内容在同目录下，文件名是文件编号。

删除群组时，发言、放入的文件目录，以及这个群组生成的媒体目录一并删除。folder 指向的文件夹不会删除。
