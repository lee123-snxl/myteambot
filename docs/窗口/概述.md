# 窗口

原生窗口，标题是「本机 Bot」。深色界面，布局仿 VS Code：最左是活动栏，旁边是侧栏，中间是带标签的编辑区，底部是状态栏。同一时间只跑一个网络请求。

离开页面时，表单若有未保存修改，会先保存。保存失败则留在当前页。

页面内容在 `src/ui.rs`。主题、活动栏、侧栏、标签条、状态栏和通知在 `src/ui/shell.rs`。资源管理器在 `src/ui/explorer.rs`。
