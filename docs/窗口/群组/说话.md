# 在群组里说话

输入框在窗口底部。Enter 或「发送」先把你的话写入这个群组。

群里的 Bot 按加入顺序一个一个回复。上一个结束后，下一个才开始。

每个对话 Bot 用自己已保存的提示词、提供方和模型。发给它的记录里，你的话以「用户：」开头，其他 Bot 的话以那个 Bot 的名字开头。它自己以前的回复仍是助手消息。失败的红字不会再发给模型。生图、语音、视频只留下说明文字，其他 Bot 只看得到这段说明。

生图、语音、视频的 Bot 不走群组提示词，也不读群组文件夹。它只用自己的提示词，加上最近一条你的原话。规则与单聊相同，见 [发送与记录](../聊天/发送与记录.md)。输入框仍是「对群组说一句，Enter 发送」。生成的文件记在这个群组下。

某个 Bot 没有提供方、没有模型，或请求失败时，群里记一条红字，后面的 Bot 继续。

对话 Bot 的回复下面同样显示这次的输入和输出 token。生图、语音、视频不显示。

群里没有 Bot 时，只记下你的话。

正在回复时不能再发，也不能删除这个群组。

群组如果保存了文件夹，对话用途的 Bot 会读取它，也可以把内容写进去。读到的文本会发给模型。详见 [文件夹](文件夹.md)。
