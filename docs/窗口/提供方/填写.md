# 填写提供方

名称必填，最多 80 字。接口类型、地址必填。API 密钥可空，给本地服务用。默认模型可空。Azure 另有 API 版本。

类型只有：openai、anthropic、gemini、ollama、azure。

按钮：保存、测试连接、读取模型、取消。已保存的还有删除，删除前要确认。取消会放弃未保存修改；新建且未保存时回到首页。

用途在名称和接口类型下面、预设上面，页面可以往下滚动。可选对话、生图、语音、视频。选对话时不写入用途。Anthropic 和 Ollama 选了生图、语音或视频时，显示「这个接口只能对话」，保存会报「这个接口不能用于该用途」。换成这两种类型时，若当前用途它们不支持，用途回到对话。

语音用途另有语音角色，最多 40 字。留空时 Gemini 用 Kore，其他用 alloy。

更换类型时，若地址仍是上一种的默认地址，就换成新类型的默认地址，并清掉已读模型。换成 Azure 且版本为空时，填上 `2024-10-21`。
