# 发送与记录

发送使用已保存的 Bot，不带上配置页里还没保存的修改。

用户消息先写入记录，再请求模型。用户在右侧蓝色气泡，回复在左侧白色气泡。失败是红色说明，下次不会再发给模型。

空回复记成错误「模型没有返回文本」。

助手回复下面显示这次消耗的输入和输出 token，形如「输入 12 · 输出 34」。接口没带回用量时不显示。同一次回复里如果读文件夹请求了多次，两项分别相加。生图、语音、视频不显示。重新打开仍然显示。

Bot 如果保存了文件夹，单聊时会读取这个文件夹，也可以把内容写进去。读到的文本会发给模型。右侧仍可浏览。详见 [文件夹](../Bot/文件夹.md)。生图、语音、视频不读、不写这个文件夹，也不带上以前的对话。

生图和视频把 Bot 提示词与这句话用空行拼在一起，提示词为空则只发这句话。语音只朗读这句话。说明见 [生图](../../接口/生图.md)、[语音](../../接口/语音.md)、[视频](../../接口/视频.md)。

等待时分别显示「正在生图…」「正在生成语音…」「正在生成视频…」。输入框提示分别是描述图片、输入要朗读的文字、描述视频。

图片能解码时显示在气泡里，最长边不超过 320。png、jpg、mp3、wav、mp4 旁有「打开图片」「打开语音」或「打开视频」，用系统打开。文件位置见 [媒体文件](../../数据/媒体文件.md)。
