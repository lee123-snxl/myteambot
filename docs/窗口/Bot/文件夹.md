# 文件夹

Bot 可以指定一个本机文件夹。留空则单聊不读写文件夹，聊天页也没有文件夹栏。

路径必须是已有文件夹的绝对路径。可以手填，也可以点「选择」。点「选择」会打开文件夹树。点一下文件夹把它选中，再点确定。保存之后才生效。

单聊时，这个 Bot 会看到文件夹里的一部分文件名和文本，也可以再读取某个文件，或把文本写进这个文件夹。读到的文本会发给模型。名为 target 或 .git 的子文件夹只列出名字，不展开。

右侧仍可浏览。点文件夹名进入，点「上级」返回。点文件名读取。写入在当前打开的这一层。

不能写出这个文件夹，也不能使用 `..`。删除 Bot 不会删除这个文件夹里的文件。
