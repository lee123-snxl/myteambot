# 资源管理器

浏览当前单聊或群组的文件。没有打开设了文件夹的单聊，也没有打开群组时，只显示一行提示。

## 文件夹

单聊时是这个 Bot 的文件夹，群组时是群组的文件夹。没保存文件夹就不出现。

分区标题是文件夹名，下面是完整路径。进了子文件夹时再显示「当前：」相对路径，第一行是「..」，点它回到上级。文件夹前面是箭头，文件前面是文件图标，后面是大小。点文件夹进入，点文件在编辑区打开预览标签。

## 写入文件

填文件名和文本，点「写入」，写在当前打开的那一层。「放入文件」从本机选一个文件复制进来。写入后在编辑区打开它。

## 群组文件

只在群组里出现。分区标题右边的「+」放入文件。列表里点文件名在编辑区打开预览标签，鼠标移到一行上会出现「×」，点它移除。

这些文件只在本机，不会发给模型。规则见 [群组文件](../群组/文件.md)。

三个分区都可以点标题收起。
