# 侧栏

活动栏右边。宽度可以拖动右边缘调整。顶部是这一栏的标题，带「+」的标题可以直接新建。

## 会话

两个可折叠分区，点分区标题收起或展开：

- 单聊：列出已保存的 Bot，点哪一个就和哪一个对话。还没有 Bot 时提示先保存。
- 群组：列出群组，名字后面是成员数。分区标题右边的「+」新建群组。

## Bot

列出已保存的 Bot，名字后面是 Bot 自己的模型，没填模型时是提供方名字。点名字进入配置。标题右边的「+」新建一个空白 Bot。

## 模型提供方

列出提供方，名字后面是接口类型和用途。点名字进入编辑。标题右边的「+」添加提供方。
