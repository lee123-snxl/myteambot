# 编辑区

窗口中间。顶部是标签条，下面是当前标签的内容。

## 标签

- 首页：「欢迎」。
- 提供方、Bot：一个标签，名字是已保存的名字，新建时是「新的提供方」「新的 Bot」。
- 单聊：Bot 名字，内容是对话。
- 群组：群组名字是对话，另有「设置」标签放名字、文件夹和成员。

在资源管理器里点了文件，会多出一个以文件名命名的预览标签，等宽字体显示正文。点标签上的「×」关闭，回到对话。一次最多一个文件夹预览和一个群组文件预览。

有未保存修改时，表单所在的标签上显示「●」。

## 标签条右边

单聊对话标签打开时，右边有「配置 Bot」和「删除对话」。「配置 Bot」进入这个 Bot 的配置页。

## 表单页

提供方、Bot、群组设置是一列表单，最宽 760。标题下面先是操作按钮，蓝色的是「保存」。字段按「常规」「连接」「模型」「提示词」「文件夹」「成员」等小节分开，可以上下滚动。

## 对话

记录占满编辑区，新消息贴在底部。输入框在对话标签的底部，切到其他标签时不显示。
