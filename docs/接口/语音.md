# 语音

提供方用途为语音。只支持 OpenAI 兼容、Azure、Gemini。其他类型返回「这个接口不能生成语音」。

只朗读用户这句话，不带系统提示、历史和文件夹。超过 4096 字返回「要朗读的文字过长」。没有用户文字返回「没有可发送的用户消息」。

语音角色来自提供方。留空时 Gemini 用 Kore，其他用 alloy。

OpenAI 兼容请求 `POST {根}/audio/speech`，带 model、input、voice，`response_format` 为 mp3。Azure 用部署路径，正文不带 model。

Gemini 用 `:generateContent`，`responseModalities` 为 AUDIO，并带 speechConfig 里的 voiceName。

直接返回的音频按 mp3 保存。JSON 里的音频同样保存。PCM 或 L16 包成 WAV，采样率默认 24000。说明是「已生成语音」。见 [媒体文件](../数据/媒体文件.md)。
