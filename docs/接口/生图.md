# 生图

提供方用途为生图。只支持 OpenAI 兼容、Azure、Gemini。其他类型返回「这个接口不能生图」。

提示是 Bot 提示词、空行、用户这句话。提示词为空则只有这句话。超过 4000 字返回「提示过长」。没有用户文字返回「没有可发送的用户消息」。不发送历史，也不读文件夹。

一次生成一张，尺寸固定 `1024x1024`。

OpenAI 兼容请求 `POST {根}/images/generations`，带 model、prompt、n。模型名以 `gpt-image` 开头时不带 `response_format`，否则为 `b64_json`。Azure 用部署路径，正文不带 model，带 `response_format`。

Gemini 模型名含 `imagen` 时用 `:predict`，`sampleCount` 为 1。其他模型用 `:generateContent`，`responseModalities` 为 TEXT 和 IMAGE。

说明优先用修订后的提示或返回里的文字，否则是「已生成图片」。保存为 png 或 jpg。见 [媒体文件](../数据/媒体文件.md)。
