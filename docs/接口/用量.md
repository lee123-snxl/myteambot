# 用量

对话响应里的 token 记在这条助手回复上。界面写在回复下面。

OpenAI 兼容、Ollama、Azure 读 `usage.prompt_tokens` 和 `usage.completion_tokens`。没有这两项时改读 `usage.input_tokens` 和 `usage.output_tokens`。

Anthropic 读 `usage.input_tokens` 和 `usage.output_tokens`。

Gemini 读 `usageMetadata.promptTokenCount` 和 `usageMetadata.candidatesTokenCount`。

字段缺失，或不是非负整数时，该项按 0。整段用量都没有时，回复上不记，界面也不显示。

同一次回复里读文件夹若请求了多次，各项相加。
