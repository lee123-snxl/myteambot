# 发往模型的内容

只发送 user 和 assistant，空内容丢掉。最多 40 条，更早的丢掉。若开头是助手消息，也丢掉，直到第一条是用户消息。

系统提示词来自 Bot，空则不发。单聊若保存了文件夹，会附上这个文件夹的一部分文件名和文本。群组附上的是群组的文件夹，不是每个 Bot 自己的。Bot 再读取的文件文本也会发给模型。Bot 填了模型，就覆盖提供方的默认模型。两边都空时不能发送。

生图、语音、视频不发送历史，也不读、不写文件夹。提示怎么拼见 [生图](生图.md)、[语音](语音.md)、[视频](视频.md)。

对话和每次媒体请求超时 120 秒。视频会按 [视频](视频.md) 轮询。测试连接和读取模型超时 20 秒。
