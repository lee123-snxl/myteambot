# 接口

五种类型。地址会去掉查询串和末尾斜杠。只有主机名的 OpenAI 兼容地址会补上 `/v1`。

用途记在提供方上：空或 chat 是对话，还有 image、speech、video。OpenAI 兼容、Azure、Gemini 可以生图、语音、视频。Anthropic 和 Ollama 只能对话。
