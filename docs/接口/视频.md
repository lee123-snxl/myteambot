# 视频

提供方用途为视频。只支持 OpenAI 兼容、Azure、Gemini。其他类型返回「这个接口不能生成视频」。

提示拼法与 [生图](生图.md) 相同，超过 4000 字返回「提示过长」。不发送历史，也不读文件夹。

OpenAI 兼容请求 `POST {根}/videos`，尺寸 `1280x720`，`seconds` 为字符串 `4`。Azure 用部署路径，正文不带 model，尺寸和秒数相同。

完成后下载 mp4。状态为完成、成功时下载；失败、取消、过期时报错；排队或进行中则继续查。每 2 秒查一次 `GET .../videos/{id}`，最多 150 次，然后 `GET .../content`。超过次数返回「视频生成超时」。每次请求仍是 120 秒。

Gemini 用 `:predictLongRunning`，`sampleCount` 为 1，`aspectRatio` 为 `16:9`，不传时长。按返回的操作名轮询，再下载 uri（附上密钥）或 base64。

说明是「已生成视频」。见 [媒体文件](../数据/媒体文件.md)。
